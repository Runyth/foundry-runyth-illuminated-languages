# Player guide

A protected document is read through one character. The module first uses your explicit **Read as…** choice, then exactly one controlled token, your assigned character, or exactly one player character you own.

If several tokens are controlled, select a character explicitly. The module never combines the languages of multiple actors.

Readable content remains normal text. Unreadable content uses the configured Polyglot script and font. A short warning appears when no actor or compatible Polyglot runtime can be used. This does not grant permission to documents you could not already access.
